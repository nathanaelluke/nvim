# nvim

Personal Neovim configuration built with `lazy.nvim`.

## Includes

- Telescope for search and navigation
- Treesitter for syntax highlighting
- `blink.cmp` for completion
- Conform for formatting
- Harpoon, Yazi, Neogit, VimTeX, and Obsidian integrations

## Setup

Clone this repo to `~/.config/nvim`:

```sh
git clone https://github.com/nathanaelluke/nvim ~/.config/nvim
```

Open Neovim once to let `lazy.nvim` install plugins.
